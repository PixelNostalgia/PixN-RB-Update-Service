#                                 Team Pixel Nostalgia
#                        Deployment and Update Service for RetroBat

We have now merged our deployment script (often referred to as the "Pixelfication Script")
with our PixN Update Service Script, so a single script can be used to turn a regular install
of RetroBat into the RGS build and then keep it updated. This means you can install our build
on pretty much any size storage and no longer need to download a large base image. Once you
have the barebones build installed, you can then browse our ROMpacks and download the ones you want.

This change also means you can run the script on any version of RetroBat, from v6.x upto the latest
version, so you no longer need to match the script version to the RetroBat version, or wait for an
updated deployment script when a new version of RetroBat is released.

Steps:

1. Download and install the latest version of RetroBat.

2. Download the current version of the script (PixN-RB-Update-Service.cmd).

3. Exclude the RetroBat folder from your Anti-Virus software (Windows Defender etc)

4. Place our script (PixN-RB-Update-Service.cmd) in \RetoBat\emulators\pixn
   (you will need to create the "pixn" folder).

5. Double-click the script to run it.

6. Wait.......make a drink etc...

7. When the script has finished, check the "- PixN_ReadMe.txt" in the root of the RetroBat folder.

8. Download any additional ROMpacks you want: https://pixelnostalgia.github.io/

9. Launch RetroBat and run the 'PixN Update Service' from the RetroBat item on the wheel.
   (Just to check you have all the latest updates. fixes etc)

10. Enjoy!
